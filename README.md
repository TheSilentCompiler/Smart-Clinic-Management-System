# Smart Clinic Management System

## 📌 Project Overview

This project is a **Smart Clinic Management System** developed using **Java (Swing GUI)** and **MySQL**.
It is designed to manage clinic operations such as patient records, doctor details, and appointment scheduling.

---

## 🎯 Features

* User Login System (Admin & Reception)
* Role-Based Dashboards
* Patient Management
* Doctor Management (Admin only)
* Appointment Booking
* View Patient Records

---

## 🧠 OOP Concepts Used

* **Encapsulation** → private fields with getters/setters
* **Inheritance** → `Person` → `Patient`, `Doctor`
* **Polymorphism** → `showDetails()` method overriding
* **Abstraction / Interface** → `Displayable` interface
* **Packages** → model, dao, ui, db

---

## 🗄️ Database

* MySQL database used
* Tables:

  * users
  * roles
  * patients
  * doctors
  * appointments

---

## ⚙️ Technologies Used

* Java (Swing)
* MySQL
* JDBC (Database Connectivity)
* IntelliJ IDEA

---

## ▶️ How to Run

1. Import project into IntelliJ IDEA
2. Setup MySQL database using provided SQL schema
3. Update DB credentials in `DBConnection.java`
4. Run `Main.java`
